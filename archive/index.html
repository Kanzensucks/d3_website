Method & data

The headline measure is hospitalised road-crash injuries per 100,000 people, which normalises for population so a small jurisdiction like the NT is comparable to a large one like NSW. The “national average” throughout is population-weighted (total cases ÷ total population), not a simple mean of state rates.

  • Sources: AIHW hospitalised road-crash injuries; ABS state/territory populations.
  • Breakdowns: road-user type, age group and sex (used in the prism/galaxy views). The road-user file omits car occupants, so a “Vehicle occupant” category is derived as total − known.
  • Built with plain D3.js v7 — no frameworks or build step.
  • Caveat: data is state-level, so “regional vs city” is shown via the NT and remote jurisdictions as a proxy; within-state remoteness data would demonstrate it directly.
